# 基于 STC89C52 的多功能电子秤

51 单片机课程设计项目。用 STC89C52 做主控，做了一个桌面电子秤，除了称重之外还带了时钟、测温、掉电存储和串口上传。

## 功能

- **称重计量**：ADC0832 采集压力传感器输出，支持去皮和超重报警
- **实时时钟**：DS1302 提供年月日时分秒，给记录打时间戳
- **温度采集**：DS18B20 单总线测温
- **掉电存储**：AT24C02 保存标定参数和最近一次称重记录
- **人机交互**：LCD1602 显示 + 8 个独立按键 + LED 指示 + 蜂鸣器报警
- **数据上传**：串口 9600bps 把称重记录发到上位机

## 硬件

| 器件 | 型号 | 数量 | 说明 |
|---|---|---|---|
| 主控 | STC89C52RC | 1 | 8051 内核 |
| 模数转换 | ADC0832 | 1 | 采集压力传感器 |
| 实时时钟 | DS1302 | 1 | 三线串行 |
| 温度传感器 | DS18B20 | 1 | 单总线 |
| 存储 | AT24C02 | 1 | I²C EEPROM |
| 显示 | LCD1602 | 1 | 16×2 字符 |
| 晶振 | 11.0592 MHz | 1 | 保证串口波特率精度 |
| 按键 | 独立按键 | 8 | 功能切换与参数设置 |
| 提示 | LED + 有源蜂鸣器 | 各 1 | 状态指示与超重报警 |

晶振用的是 11.0592 MHz 而不是 12 MHz，这样定时器分频后能得到准确的 9600bps 波特率。

## 引脚分配

| 信号 | 引脚 |
|---|---|
| ADC0832 CS / CLK / DIO | P3.5 / P3.6 / P3.7 |
| 按键 K1–K8 | P1.0 – P1.7 |
| LED / 蜂鸣器 | P3.4 / P3.3 |
| 串口 TXD / RXD | P3.1 / P3.0 |

DS1302、LCD1602、AT24C02、DS18B20 的引脚在各自的头文件里定义。

## 怎么跑起来

**仿真运行（不需要硬件）**

1. 用 Proteus 8 打开 `仿真电路/New Project.pdsprj`
2. 双击 MCU 元件，*Program File* 选 `程序源码/The_Project.hex`
3. 时钟频率设成 `11.0592 MHz`，点运行

**编译源码**

1. 用 Keil μVision4 / C51 打开 `程序源码/The_Project.uvproj`
2. 按 F7 编译，生成的 hex 在 `程序源码/The_Project.hex`

**烧录到实物**

用 STC-ISP 通过串口把 hex 下载到 STC89C52RC 就行。

## 几个注意点

- 源码是 **GB2312/GBK** 编码（Keil C51 默认），用 VS Code 打开要手动选成 GBK，不然中文注释会乱码。
- ADC0832 和 DS1302 都没有硬件外设支持，全部靠 GPIO 拉高拉低加延时来模拟时序，延时长度不对通信就会失败。
- DS18B20 的单总线对时隙宽度更敏感，复位脉冲、存在脉冲、读写时隙都得按手册的微秒级要求来。
- 8 个按键统一在 `key_deal()` 里扫描，用 `key_status[8]` 记录当前菜单层级；显示刷新集中在 `display_deal()`，负责把变量拆成 LCD1602 能显示的字符。

## 还能继续做的

1. 把 `display_deal()` 和 `key_deal()` 里的重复代码抽出来，用函数指针数组做菜单跳转
2. 用定时器中断代替 `delayms()` 阻塞延时，按键响应会跟手很多
3. 标定流程加多点线性拟合，做成自动校准
4. 串口协议加上帧头帧尾和校验和
5. 加低功耗休眠模式
